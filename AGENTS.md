# Agent context

Долгоживущий контекст пользователя хранится в Obsidian vault:

- **На Mac:** `~/Documents/CursorContext`
- **В этом репозитории (шаблон):** `Documents/CursorContext/`

Перед нетривиальными задачами читай `Documents/CursorContext/20-Context/` и релевантные `10-Projects/`.  
После важных решений обновляй vault (см. `Documents/CursorContext/AGENTS.md`).

Cloud Agent не использует Obsidian MCP — только файлы `.md` в vault (синхронизируй vault через git в private repo или submodule).
