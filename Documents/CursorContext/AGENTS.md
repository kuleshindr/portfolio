# Cursor Context Vault (Obsidian)

Эта папка — единый контекст для **локальных** и **облачных** агентов Cursor.

## Где что лежит

| Папка | Назначение |
|-------|------------|
| `00-Inbox/` | Быстрые захваты, итоги чатов, черновики |
| `10-Projects/` | Контекст по проектам (одна подпапка = один проект) |
| `20-Context/` | Долгоживущее: стек, люди, предпочтения, глоссарий |
| `30-Daily/` | Daily notes (`YYYY-MM-DD.md`) |
| `templates/` | Шаблоны для новых заметок |

## Как агенту работать с vault

### Облачный агент (Cloud Agent)

- MCP Obsidian **недоступен** (vault на вашем Mac не в localhost облака).
- **Всегда** читай и пиши `.md` файлы **напрямую** в этом vault (пути от корня vault).
- Перед задачей по коду: проверь `10-Projects/<имя>/` и `20-Context/` на релевантные заметки.
- После значимой работы: обнови или создай заметку (решения → `decisions.md`, итог → Inbox или daily).

### Локальный агент (Mac, vault открыт в Cursor)

- Предпочитай **правку файлов** в vault (быстро, работает без Obsidian).
- Если включён MCP `obsidian` и Obsidian запущен — можно искать vault-wide и патчить секции через MCP.
- Не дублируй большие блоки: короткая выжимка + ссылка `[[wiki-link]]` или путь к файлу в репо.

## Формат заметок

```yaml
---
title: Краткий заголовок
date: YYYY-MM-DD
tags: [cursor, project-name]
project: optional-slug
---
```

- Язык: как у пользователя в чате (часто русский).
- **Не** сохраняй пароли, API-ключи, `.env` — только безопасные указатели («ключ в 1Password / env VAR_NAME»).

## Триггеры пользователя

Если пользователь просит **запомнить / зафиксировать / записать в Obsidian / обновить контекст**:

1. Выбери папку по таблице выше.
2. Создай или дополни `.md` (шаблоны в `templates/`).
3. Добавь 1–3 wiki-ссылки на связанные заметки.
