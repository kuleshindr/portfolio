# ИРАН v2_3 — актуализация маркеров после новой озвучки

Сиквенция **ИРАН v2_3**: после подмены дорожки диктора старые таймкоды маркеров (`11:33`, `12:45`, `6:13`, из «Иран правки» и т.д.) **больше не привязаны к звуку**. Ниже — что закрыть, что проверить по **фразе в новой VO**, что оставить как **картинка/монтаж**.

Источники: [iran-scenariy-pravki-razmetka](https://docs.google.com/document/d/1cKIVP1AXE7wgQzxS7TTmbDfdyxuMeh4xTRHRwTMMPY4/edit), [Иран правки](https://docs.google.com/document/d/1o68aVywQuuF-tIhunNK5pkUnuoaFiPk9egzEMOyUApc/edit).

## Как обновить маркеры в Premiere (кратко)

1. **Sequence → Markers** — отфильтровать/удалить все с «VO / озвуч / переозв» с **устаревшим TC**.
2. По дорожке диктора: **поиск по тексту** (если есть транскрипт) или прослушивание по таблице **SearchInVO**.
3. На найденной фразе: **M** — новый маркер; в Comment — `MarkerName` из CSV.
4. Маркеры **picture/montage** ставить на **видео**, якорь — ближайшая узнаваемая фраза из колонки SearchInVO.
5. Экспорт для бэкапа: **Markers → Export Markers** (CSV).

## Легенда категорий

| Category | Значение |
|----------|----------|
| `vo_done` | Должно уже быть в новой зачитке — маркер «переозвучить» снять после проверки фразы |
| `vo_verify` | Обязательно найти фразу; если нет — дозапись или монтажный маркер |
| `vo_cut_verify` | Фразы **не должно** быть; если есть — вырезать |
| `picture` / `montage` | Не зависит от смены VO; **переставить** маркер на новый TC по якорю |

## Частые «слетевшие» случаи

- Маркеры на **6:13–6:25 (Лаврентьев)** — после правки VO **куска нет**; маркер «вырезать» → удалить, проверить только отсутствие слова «Лаврентьев».
- Маркеры **вставок** с TC 11:33 / 12:45 / 15:23 / 16:30 — искать по **«Орлиный коготь»**, **«Винсеннес»**, **«Сулеймани»**, **«Амини»**.
- **«режим»** (12:59, 13:28, 16:46, 19:02 в правках) — в VO должны быть замены; **субтитры и титры в кадре** проверить отдельно.
- В разметке сценария **нет абзаца WWII** в экспорте между 1935 и «После войны» — в v2_3 **обязательно** прослушать блок про ввод войск (ленд-лиза).
