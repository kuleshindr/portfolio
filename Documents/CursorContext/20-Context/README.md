# Долгоживущий контекст

Заполни по мере работы:

- `preferences.md` — как ты хочешь, чтобы агенты отвечали и оформляли заметки
- `stack.md` — языки, фреймворки, хостинг
- `people.md` — команда, контакты (без секретов)

Агенты должны **обновлять** эти файлы, когда ты явно просишь что-то «запомнить навсегда».
